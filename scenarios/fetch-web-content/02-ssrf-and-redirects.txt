# Direct DNS validation: mixed public + private IP (DNS rebinding), empty answer, lookup failure (FW-4, D8, I2)
> dns set rebind.example.com 93.184.216.34 10.0.0.5
dns: rebind.example.com -> 93.184.216.34, 10.0.0.5

> origin serve https://rebind.example.com/ 200 <p>should not be reached</p>
origin: 200 https://rebind.example.com/

> fetch html https://rebind.example.com/
error: Blocked Target URL: hostname "rebind.example.com" resolved to private IP "10.0.0.5"

> origin last-headers https://rebind.example.com/
(not requested)

> dns empty empty.example.com
dns: empty.example.com -> (empty)

> fetch html https://empty.example.com/
error: Blocked Target URL: DNS lookup returned no addresses for "empty.example.com"

> dns fail missing.example.com ENOTFOUND
dns: fail missing.example.com

> fetch html https://missing.example.com/
error: Blocked Target URL: DNS lookup failed for "missing.example.com": ENOTFOUND

# Relative redirect on same origin preserves Authorization and Cookie headers (FW-6, D9, I4)
> origin redirect https://origin-a.example.com/old 301 /new
origin: redirect 301 https://origin-a.example.com/old -> /new

> origin serve https://origin-a.example.com/new 200 <p>same-origin</p>
origin: 200 https://origin-a.example.com/new

> fetch html https://origin-a.example.com/old --header Authorization:Bearer-tok --header X-Trace:1
| <p>same-origin</p>

> origin last-headers https://origin-a.example.com/new
header: Authorization: Bearer-tok
header: X-Trace: 1

# Cross-origin redirect strips Authorization, Cookie, and Proxy-Authorization while preserving X-Trace (FW-6, D9, I4)
> origin redirect https://origin-a.example.com/jump 302 https://origin-b.example.com/final
origin: redirect 302 https://origin-a.example.com/jump -> https://origin-b.example.com/final

> origin serve https://origin-b.example.com/final 200 <p>cross-origin</p>
origin: 200 https://origin-b.example.com/final

> fetch html https://origin-a.example.com/jump --header Authorization:Bearer-secret --header Cookie:sid=123 --header Proxy-Authorization:Basic-xyz --header X-Trace:abc
| <p>cross-origin</p>

> origin last-headers https://origin-a.example.com/jump
header: Authorization: Bearer-secret
header: Cookie: sid=123
header: Proxy-Authorization: Basic-xyz
header: X-Trace: abc

> origin last-headers https://origin-b.example.com/final
header: X-Trace: abc

# Redirect to private IP or disallowed scheme is blocked BEFORE connecting to the target (FW-6, D8, I1)
> origin redirect https://example.com/to-private 302 http://127.0.0.1/secret
origin: redirect 302 https://example.com/to-private -> http://127.0.0.1/secret

> origin serve http://127.0.0.1/secret 200 <p>top-secret</p>
origin: 200 http://127.0.0.1/secret

> fetch html https://example.com/to-private
error: Blocked Target URL: private address "127.0.0.1"

> origin last-headers http://127.0.0.1/secret
(not requested)

> origin redirect https://example.com/to-file 302 file:///etc/passwd
origin: redirect 302 https://example.com/to-file -> file:///etc/passwd

> fetch html https://example.com/to-file
error: Blocked Target URL: disallowed scheme "file:" (only http: and https: are allowed)

# Redirect to hostname resolving to a private IP is blocked BEFORE connecting (FW-6, D8, I2)
> origin redirect https://example.com/to-rebind 302 https://rebind.example.com/
origin: redirect 302 https://example.com/to-rebind -> https://rebind.example.com/

> fetch html https://example.com/to-rebind
error: Blocked Target URL: hostname "rebind.example.com" resolved to private IP "10.0.0.5"

# Redirect loop exceeding 10 hops fails explicitly (FW-6, D9, D14)
> origin redirect https://example.com/loop 302 https://example.com/loop
origin: redirect 302 https://example.com/loop -> https://example.com/loop

> fetch html https://example.com/loop
error: Too many redirects (exceeded 10)

# Redirect status without Location header is treated as non-2xx HTTP error (FW-6, D14, D17)
> origin serve https://example.com/no-location 302 Moved
origin: 302 https://example.com/no-location

> fetch html https://example.com/no-location
error: HTTP error 302 fetching https://example.com/no-location
